# Car Rental Management System

A full-stack car rental platform built with **Laravel** and **Filament** for managing vehicle rentals in North Sumatra, Indonesia.

The system provides separate interfaces for **administrators** and **customers**. Administrators can manage vehicles, customers, rentals, and payments through a Filament-based dashboard, while customers can register, verify their identity, browse vehicle availability, make bookings, and complete payments.

### Key Features

* Vehicle and fleet management
* Customer registration, authentication, and identity verification
* Date-based vehicle availability checking
* Rental and booking management
* Automated rental status lifecycle
* Payment tracking and processing
* Luxury vehicle pricing with configurable premium rates
* Email notifications for verification, booking, and payment events
* RESTful API under `/api/v1/`
* Laravel Sanctum authentication
* Responsive Filament admin panel
* Indonesian-language administrative interface
